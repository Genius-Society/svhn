This project is a _PyTorch_ implementation that uses deep CNN to recognize multi-digit numbers using the Street View house numbers (SVHN) dataset derived from Google, each picture contains a set of numbers from 0 to 9, the model is tested to have 89% accuracy. For training code, please visit [main branch](https://github.com/Genius-Society/svhn/tree/main)
